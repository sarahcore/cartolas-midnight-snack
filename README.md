# 🐱 Cartola's Midnight Snack

A small Scratch game inspired by my real-life cat, Cartola.

This project was my first experience with Scratch and also my first time creating a game using visual programming. I kept the scope relatively simple so I could focus on learning and experimenting with programming fundamentals while building something personal and fun.

In the game, Cartola tries to catch falling food while the difficulty gradually increases. The player has three lives, and a special catnip power-up temporarily changes Cartola's state and slows down the falling food.

> 🇧🇷 **Language note:** This project was developed in Brazilian Portuguese (PT-BR) as part of an academic programming activity in Brazil. Therefore, variable names, messages, and some in-game elements are written in Portuguese.

## 🎮 How to Play

Move Cartola horizontally using your mouse and catch the falling food.

- 🐟 Catch food to earn points.
- ❤️ You have 3 lives. Missing food costs one life.
- ⚡ The game becomes faster as you progress through the stages.
- 🌿 Catch the catnip for a temporary power-up: Cartola changes state and the falling food slows down for 7 seconds.
- 🏆 Reach 40 points to win!

## 💻 Programming Concepts

While developing the game, I experimented with several programming concepts using Scratch's visual programming environment:

- **Events** — starting the game and communicating between sprites through broadcast messages.
- **Variables** — controlling points, lives, stages, speed, and the catnip power-up state.
- **Conditionals** — checking collisions, lives, score milestones, and game states.
- **Loops** — continuously controlling movement and checking game conditions.
- **Collision detection** — detecting when Cartola catches food or catnip.
- **Randomization** — changing where falling objects appear.
- **Difficulty progression** — increasing the falling speed as the player reaches new stages.
- **State management** — changing Cartola's costumes depending on whether she is eating or under the catnip effect.

- ## 🌱 Development & Learning

This project was a learning experience from start to finish. Since it was my first time using Scratch and creating a game in this format, I started with a small idea and gradually added new mechanics as I became more comfortable with the platform.

During development, I also encountered unexpected behaviors, especially when multiple events and character states were happening at the same time. Debugging these situations helped me better understand how events, variables, timing, and conditions interact with each other.

More than creating a complex game, my goal with this project was to experiment, make mistakes, understand why they happened, and learn by building.

## 📦 Project File

The complete Scratch project is available in this repository as an `.sb3` file.

To run the game:

1. Download the `.sb3` file from this repository.
2. Open [Scratch](https://scratch.mit.edu/).
3. Select **File → Load from your computer**.
4. Open the downloaded project file.
5. Click the green flag to start playing. 🟢
